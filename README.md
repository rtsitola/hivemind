# HiveMind

Intelligence collective décentralisée pour groupes et organisations.

**Phase 1 — Un esprit, un groupe.**

👉 **[Documentation complète →](hivemind/README.md)**

## Quick start

```bash
git clone https://github.com/rtsitola/hivemind.git
cd hivemind
export PYTHONPATH=$(pwd)
python3 -m hivemind.hivemind_cli init mon-cabinet
```
